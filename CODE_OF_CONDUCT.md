# Code of Conduct

This is a small homelab project. Be specific, be kind, and assume good intent.

- Critique code and docs, not people.
- No harassment, slurs, or baiting.
- Do not post contents of other people's `docker.sock` output, `.env` files, or internal URLs in issues.
- Feature requests that turn Port-Light into Portainer will be closed with a pointer to [docs/roadmap.md](docs/roadmap.md) — that is scope, not a personal rejection.

If someone is making the tracker unusable, the maintainer will block them. To report a conduct problem privately, use the same channel as [SECURITY.md](SECURITY.md).
